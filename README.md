# AI-Based Peak Hour Electricity Prediction

This project predicts peak electricity consumption hours for university dormitories using Machine Learning and visualizes results using a Streamlit dashboard.

## Features
- Synthetic electricity usage data generation
- Moving average smoothing for noise reduction
- Linear Regression-based peak hour prediction
- Interactive Streamlit + Plotly dashboard
- Peak load alert system

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Plotly

## How to Run
```bash
python data_generator.py
python model.py
streamlit run app.py
